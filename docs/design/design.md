请为当前 Agent 页面建立一套轻量、统一、可落地的视觉规范，并基于规范调整全局样式。

目标风格：
现代、克制、干净、轻量，参考 Claude / ChatGPT / Cursor 这类主流 AI 产品的感觉。不要后台系统感，不要开发调试工具感，不要过度装饰。

请重点统一以下内容：

1. 颜色系统
- 页面背景色
- 卡片/浮层背景色
- 主文字、次级文字、弱提示文字
- 边框颜色
- hover 背景
- 主操作色
- 成功、警告、错误状态色
- inline code / 路径 / 文件名高亮色

要求：
颜色要克制、低饱和、统一。不要出现太多不同的橙色、灰色、绿色。

2. 字号和字重
请定义并落地：
- 页面标题
- 会话列表标题
- 正文
- 次级说明
- meta 信息
- 按钮文字
- 标签文字
- 代码/路径文字

要求：
不要字号层级混乱，不要所有文字都一样重。

3. 间距系统
请统一：
- 页面外边距
- 主内容区上下间距
- 消息之间间距
- 卡片内部 padding
- 按钮间距
- 列表项间距
- 输入框内部间距

要求：
整体更有呼吸感，但不要空得松散。

4. 圆角、边框、阴影
请统一：
- 普通按钮圆角
- 输入框圆角
- 卡片圆角
- tag / badge 圆角
- 弹层圆角
- 边框粗细和颜色
- 阴影强度

要求：
减少重边框、重阴影。优先使用细边框、浅背景和留白建立层级。

5. 交互状态
请统一：
- hover
- active
- focus
- disabled
- loading
- selected
- pending
- success
- error

要求：
所有可点击区域 hover 时需要有清晰但克制的反馈；禁用态不要显示可点击感。

执行要求：
- 优先抽象公共 class、theme token、CSS variables 或公共组件样式。
- 不要到处写零散样式补丁。
- 保证现有功能不受影响。
- 调整后整体页面应该更统一、更轻、更像成熟 AI 产品。

验收标准：
1. 页面颜色、字号、间距、圆角、边框、阴影明显更统一。
2. 不同模块之间不再像临时拼接。
3. 整体风格更克制、现代。
4. 没有强烈后台系统感。
5. 不影响现有交互和布局。
